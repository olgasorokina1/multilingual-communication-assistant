# Style guide

> **Known issue found in the test:** the Ukrainian friendly greeting example below says "Даніеле". The correct vocative is **"Даніелю"**. The AI copied this mistake from the guide. The file is kept as it was used in the test.

Rules for business emails from a Spanish office (gestoría / small business) to clients.
Source emails are in English. Target languages: Spanish (ES), Ukrainian (UK), Russian (RU).

Letters 01-02 are formal. Letters 03-04 are friendly.

## Spanish (ES)

| Item | Formal | Friendly |
| --- | --- | --- |
| Form of address | usted | tú |
| Greeting | Estimado Sr. Ortega: / Estimada Sra. Vidal: | Hola, Daniel: |
| Closing | Un cordial saludo, | Un saludo, |
| Date | 4 de marzo de 2026 | 4 de marzo de 2026 |
| Amount | 580,80 € / 1.089,00 € | same |
| Time | 9:30 | same |

Note: in Spanish the greeting ends with a colon (:), not a comma.

## Ukrainian (UK)

| Item | Formal | Friendly |
| --- | --- | --- |

| Greeting | Шановний пане Ортего! / Шановна пані Відаль! | Добрий день, Даніеле! |
| Closing | З повагою, | Гарного дня! |
| Date | 4 березня 2026 р. | same |
| Amount | 580,80 € / 1 089,00 € | same |
| Time | 9:30 | same |

Note: names in the greeting use the vocative case (пане Ортего, Даніеле).

## All languages

- Keep all numbers, dates, amounts, invoice and order numbers exactly. Only the format changes (decimal comma, date words).
- Keep company names, addresses, phone numbers and "NIF" as in the source.
- Use the glossary terms.
- Do not add or remove information.
